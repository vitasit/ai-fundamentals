# AI-901 Oefeningen — overzicht met links

AI-901 Ranger-sessies — alle E1–E11 met directe links naar de bijbehorende Microsoft Learn-modules.

> Alle links zijn gecontroleerd op learn.microsoft.com (september 2026). Modules met **(verdieping)** gaan verder dan het AI-901-niveau, maar zijn nuttig omdat oefeningen E5 en E6 in C#/.NET werken — de codevoorbeelden in deze modules staan meestal in Python; de concepten (client initialiseren, prompts versturen, tools koppelen) gelden ook voor de C#/.NET-aanpak uit de demo-voorbereiding.
